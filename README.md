# Тверь по QR-кодам

Страницы с информацией открываются по QR-коду. В меню (кнопка-бургер справа сверху) есть:
**Коллекция**, **Достижения**, **Вход / Регистрация**.

## Стек
Node.js (Express) · PostgreSQL · HTML/CSS/JS без фреймворков.

## Запуск
1. Установите Node.js 18+ и PostgreSQL.
2. Создайте базу: `createdb tver_qr` (или через pgAdmin).
3. `npm install`
4. Скопируйте `.env.example` в `.env`, укажите `DATABASE_URL`, `JWT_SECRET`, `BASE_URL`.
5. `npm start` (таблицы создадутся сами) и откройте http://localhost:3000
6. `npm run qr` — PNG с QR-кодами появятся в папке `qr/`.

## Структура
- `pages/` — ваши 6 страниц (вёрстка не изменена; меню добавляется при отдаче)
- `config/pages.js` — каталог страниц: название и описание для коллекции
- `config/achievements.js` — достижения и правила их выдачи
- `routes/`, `services/`, `middleware/`, `db/` — сервер и работа с БД
- `public/` — меню, коллекция, достижения, вход (HTML/CSS/JS)
